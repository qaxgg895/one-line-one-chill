## The entry

One single sentence of horror, 91 characters, meant to frighten a reader
in one breath:

> The dentist found a second set of teeth growing behind mine, and they were already chewing.

No mirror, no doll, no basement, no "it was behind me". The scare is
inside the reader's own mouth: a second set of teeth, already at work,
that nobody invited and nobody can take out. The last word lands the
blow — they are not coming, they are already chewing.

## How to run

`main.ts` (run with `node main.ts`) writes exactly that one line — and
nothing else, no trailing newline, no gloss — to `/output/entry.txt`. It
validates the line in code (a single line, 1 to 200 characters, not only
whitespace) before writing it, so the output always passes the
competition's gate.

```sh
node main.ts
```
